本文档用于在 AutoSeg3D 的 **SV（单帧）** 训练设置下，做 4 个与 baseline 可比的对照实验（A1–A4）。
要求：
- 模型类保持 `type='ScanNet200MixFormer3D'`（offline，不使用 `ScanNet200MixFormer3D_Online` / 不引入 `model.memory`）。
- 除了 2D 分支相关的 metadata/pipeline 与模块开关外，其余超参（数据增强、batchsize、优化器等）尽量与 `configs/scannet200/AutoSeg3D_sv_scannet200.py` 一致。

## 公共前置

### 环境
- conda env：`ESAM`
- 在 `AutoSeg3D` 目录运行，确保能 import：`PYTHONPATH=$(pwd):$PYTHONPATH`

### GDINO 权重与路径（已在代码中作为默认值，但这里显式记录）
- repo：`/home/nebula/xxy/GroundingDINO`
- config：`/home/nebula/xxy/GroundingDINO/groundingdino/config/GroundingDINO_SwinB_cfg.py`
- checkpoint：`/home/nebula/xxy/dataset/models/groundingdino_swinb_cogcoor.pth`

### 2D-3D 对齐（SV）额外 pipeline（所有 A1–A4 共用）
这些 transform **不改变** 3D 增强，只补齐 metadata 与 raw 点缓存：
- `SavePointsForProjection`：在 3D aug 前缓存 `points_raw`
- `PrepareSVForOnline`：把 SV 的 `img_path/pose` 改写成 `img_paths/poses`（T=1）
- `BuildCamInfoFromPoses`：构造 `cam_info`（intrinsics + pose + img_size）
- `ResizeForGDINO(target_size=(420,560))`：更新 intrinsics 与 `img_size_gdino`
- `NormalizeCamInfo(strict=True)`：把 cam_info 规范成可投影用的 tensor 结构

## A1–A4 实验定义

### A1：只加 2DCA（GDINO object-level DACA-2D）
- config：`configs/scannet200/AutoSeg3D_sv_scannet200_A1_2dca.py`
- 变化：只开启 `train_cfg/test_cfg.gdino_daca2d(enable=True, mode='fuse')`；不启用 point-level early fusion（UNet 输入仍为 3 通道 RGB）
- 预期：验证“只加 2D object-level cross-attn（SP 域 DACA-2D）”的增量是否有效

### A2：early fusion + 2DCA
- config：`configs/scannet200/AutoSeg3D_sv_scannet200_A2_earlyfusion_2dca.py`
- 变化：启用 `gdino_point_fusion`（单层 level0），把每点 2D feature（256d）拼到 RGB 后面输入 UNet；同时保留 A1 的 2DCA
- 注意：UNet `in_channels` 从 3 → 259，需要 **inflate** Mask3D 预训练 ckpt（见下方）

### A3：FPN 注入 + 2DCA（AutoSeg3D loss）
- config：`configs/scannet200/AutoSeg3D_sv_scannet200_A3_fpn_2dca_autoloss.py`
- 变化：point fusion 由单层 → 多层 `feat_levels=[0,1,2,3]`（多层采样后做 avg），同时保留 A1 的 2DCA；loss 仍用 AutoSeg3D baseline

### A4：FPN 注入 + 2DCA（SegDINO3D-style matcher/loss）
- config：`configs/scannet200/AutoSeg3D_sv_scannet200_A4_fpn_2dca_segdino_loss.py`
- 变化：在 A3 基础上：
  - `decoder.bbox_flag=True`（开启 axis-aligned bbox head）
  - matcher 增加 `CenterL1Cost/SizeL1Cost`
  - inst loss_weight 增加 center/size L1 权重（并把 score loss 权重置 0）
  - `train_cfg.compute_gt_bboxes_3d=True`：SV 不提供 bboxes_3d，训练时从 GT mask + 点坐标在线计算 GT bbox

## A2/A3/A4 的预训练 ckpt inflate（必做一次）
baseline 预训练 `mask3d_scannet200.pth` 的第一层是 `in_channels=3`，但 early fusion 需要 `3+256=259`。
在开始 A2/A3/A4 前先运行：

```bash
cd /home/nebula/xxy/AutoSeg3D
/home/nebula/miniconda3/envs/ESAM/bin/python tools/inflate_mask3d_inchannels.py \
  --src work_dirs/tmp/mask3d_scannet200.pth \
  --dst work_dirs/tmp/mask3d_scannet200_in259.pth \
  --in-channels 259
```
